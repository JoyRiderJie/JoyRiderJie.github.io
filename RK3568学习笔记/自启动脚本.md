# 系统中原自启动脚本分析



## 源码

```bash
#!/bin/sh

# Start all init scripts in /etc/init.d
# executing them in numerical order.

for i in /etc/init.d/S??* ;do # for循环的范围由通配符 ?与*确定，其中通配符 ? 的作用是匹配一个数字，而 * 的作用是万能通配符，能够匹配任意长度的字符。

     # Ignore dangling symlinks (if any).
     [ ! -f "$i" ] && continue # 判断当前文件是否是普通文件，如果当前文件不是普通文件则遍历下一个文件

     case "$i" in # shell脚本中 switch ……case语句
        *.sh) # switch ……case语句中 条件为 *.sh 时执行这部分代码，即当前文件为.sh文件就会执行当前文件
            # Source shell script for speed.
            (
                trap - INT QUIT TSTP # 这个命令禁用了对INT（中断信号）、QUIT（退出信号）和TSTP（停止信号）的trap处理，这意味着这些信号将不会被当前脚本捕获，而是会传递给子进程
                set start # 设置shell的启动模式，start参数告诉shell在执行命令时应该忽略任何未定义的变量
                . $i
            )
            ;; # 这个符号表示case语句中的一个模式匹配分支结束。每个分支必须要添加
        *)
            # No sh extension, so fork subprocess.
            $i start # 对于不以.sh结尾的脚本，脚本将创建一个新的子进程来执行$i文件，并传递start作为参数。
            ;;
    esac
done
```

# 如何添加自定义的自启动脚本



那么，我们定义自己的自启动脚本实际上只需要添加一个有执行权限的 ```S??*.sh```文件即可，系统自动启脚本会加载这个脚本。

在这里我们可以撰写一个测试脚本，脚本的主要内容是开机后自动输出 **Hello, I am a test output!** 。详细脚本如下：

```bash
#!/bin/bash

echo "Hello, I am a test output!"
```

撰写完成后，为了匹配代码一部分的规则，我们可以将脚本名字修改成 **S99_test.sh** ，注意最好不要跟路径下的文件名重合。
